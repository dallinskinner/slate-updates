# Slate updates

Signed apt repository for [Slate](https://dallinskinner.github.io/slate-updates/), a Debian-based desktop OS.
Slate installs read updates from here automatically.

Slate 0.1 (Agate) installs, run once:

    curl -fsSL https://dallinskinner.github.io/slate-updates/join-updates.sh | sudo sh
